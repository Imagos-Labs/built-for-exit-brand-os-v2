# Color

Dark is canonical. Near-black grounds carry everything; **Exit Yellow appears only at value moments** (the score, the CTA, the one rising line) and never on more than ~8% of a surface. All roles live in [`tokens.css`](/brand/tokens.css) and `brand.json#tokens.color`.

## The one rule

Exit Yellow is a scalpel, not a paint bucket. In any composition it marks **exactly one thing** — the number that matters, the call to action, the "after" column. Steel and Soft White carry everything else. If yellow is on more than ~8% of a surface, pull back.

## Why this palette

| Color | Means |
|---|---|
| **Near-black** | engineered, institutional, defense-grade calm |
| **Exit Yellow** | the single value moment — freedom, the result, the go |
| **Steel + graphite** | the system underneath: structure, panels, hairlines |

## Surfaces

- **No shadows, ever.** Depth comes from 1px steel borders and the carbon/graphite step, not drop shadows.
- A **light inversion** exists (white ground, near-black ink, yellow accent) for invoices and the rare print surface — see `templates/invoice.html`. Dark is the default everywhere else.

:::tip[Tokens are the source of truth]
The portal, the landing page, and any generated site or deck all pull from `tokens.css`. Change a hex once, there.
:::
