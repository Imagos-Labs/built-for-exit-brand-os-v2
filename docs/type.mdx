# Type

## Scale

| Role | Token | Size |
|------|-------|------|
| Display | `--bfx-text-display` | clamp → 96px |
| H1 | `--bfx-text-h1` | clamp → 56px |
| H2 | `--bfx-text-h2` | clamp → 36px |
| Body | `--bfx-text-body` | 17px |
| Label | `--bfx-text-label` | 12px tracked caps |

## Pairing rules

- **Display (grotesk)** for headlines and the wordmark: uppercase, bold/black, tight line-height, large.
- **Inter** for everything functional: body, UI, captions.
- **IBM Plex Mono** for every number — scores, valuations, stats, invoice line-items, dashboards.
- **Tracked caps** (letter-spacing 0.14em, muted gray) for eyebrows and labels.
- Keep body legible at every size. No display face below ~18px.
