# Golden Atomic Brand References

The pillar of the brand OS. **A rulebook tells a model what to do; golden references show it what good looks like.** These are the canonical exemplar assets that *are* the Built for Exit visual universe, fed back into an image model as in-context references to generate net-new on-brand assets.

## How to use a GABR

Pass the reference image(s) to your image model alongside the [master prompt](/generation-layer), then describe the *new* asset. The references lock the universe (dark ground, the one accent, the finish); your prompt varies the subject. To **add** a new reference, follow the hosted [`create-gabr`](/brand/generation-layer/skills/create-gabr/SKILL.md) skill: scope it against the set, generate for coherence by passing the nearest GABRs in, validate with a human, store the prompt + refs + alt text, register it in `brand.json`, and regenerate `brand.txt`.
