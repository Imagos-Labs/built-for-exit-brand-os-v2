# Built for Exit — Master Prompt (v2)

```text
Visual asset for Built for Exit, a firm that transforms founder-dependent businesses into transferable assets. Core idea: transferability creates freedom. The register: a private equity firm, a luxury automotive brand, and an elite operating-system company had a child. Should feel like Porsche, Blackstone, Anduril, Palantir, Linear, Stripe Press. Must NOT feel like a startup guru, a business coach, a consultant, a marketing agency, or a SaaS startup.

Mood: engineered, deliberate, institutional, calm authority. Never playful, never hype, never motivational. Generous negative space. Quiet confidence.

Palette (mandatory, dark is canonical): near-black ground #050505, with #0F0F10 and #1A1A1D for panels and #2D2D31 for hairline borders. Text and key forms in soft white #F3F3F3, secondary detail in muted gray #9A9A9F. Exactly ONE accent — Exit Yellow #DFFF00 — used sparingly, marking a single value moment per composition (the score, the CTA, the one rising line). Never more than a small fraction of the frame is yellow. No second saturated color.

Surfaces and finish: flat and matte. NO drop shadows, NO glossy 3D, NO gradients, NO neon glow, NO bloom. 1px steel borders, 16px card corners. Clean and exact, like a hardware UI or a defense-grade dashboard.

If the asset is PHOTOGRAPHY: black-and-white or heavily desaturated. The founder ALONE — never smiling teams, never stock photos, never conference rooms. Settings: empty office at night, a private hangar, an airport, a warehouse, a manufacturing floor, a control room, documentation and process maps on a wall. Dramatic, restrained, cinematic, single-subject. A small Exit-Yellow element may anchor one point of the frame.

If the asset is a DIAGRAM, CHART, or ICON: outlined, geometric, minimal line work on the near-black ground. NO illustration, NO filled cartoon icons, NO gradients. Founder-at-center dependency diagrams, before/after tables, monochrome data scorecards, five-pillar radar. Numbers always set in IBM Plex Mono; labels in tracked uppercase.

Type in image (only if explicitly requested): heavy oblique grotesk (Neue Haas Grotesk Display register; Helvetica/Inter Tight acceptable), uppercase, tight line-height, large scale for headlines; IBM Plex Mono for any number. Prefer to reserve a clean band and stamp the real wordmark afterward rather than letting the model draw text from scratch.

Signature: the Hollow 4 (a bold, slightly oblique outlined numeral 4 in Exit Yellow) may appear quietly as a watermark, badge, or footer element. Never overuse it.
```
