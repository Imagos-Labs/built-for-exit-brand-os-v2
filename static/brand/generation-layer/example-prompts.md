# Built for Exit — Example Prompts

Each prompt is master-prompt + the per-asset description below. Pass the listed reference image(s) to the model. These are the patterns; copy and adapt.

## Founder-alone hero (photographic)

> [master prompt] Then: A single founder standing alone in an empty office at night, floor-to-ceiling windows, city dark behind. Shot from behind / three-quarter, contemplative, in control. Black-and-white, high contrast, cinematic, a lot of negative space. One small Exit-Yellow element somewhere in frame (an exit sign, a screen edge). No other people. No text.

Ref: `golden-atomic-brand-references/gabr-08-founder-alone.png`

## Control room / hangar (photographic)

> [master prompt] Then: A lone operator in a dark control room of monitors, or a single figure beside a private jet in a hangar. Heavily desaturated, near-black, institutional, defense-grade calm. One Exit-Yellow accent. No team, no stock-photo energy.

Ref: `golden-atomic-brand-references/gabr-09-control-room.png`

## Dependency diagram (vector)

> Founder at the center of a node graph, every business function (Sales, Operations, Finance, Hiring, Delivery, Decisions) wired back to that one node. Near-black ground, 1px steel lines, soft-white labels in tracked caps, the founder node ringed in Exit Yellow and tagged "SINGLE POINT" in mono. Outlined geometric only, no illustration, no shadow.

Ref: `golden-atomic-brand-references/gabr-04-dependency-diagram.svg` (authored as SVG — edit directly)

## Exit Readiness scorecard (vector)

> A monochrome scorecard: big mono "72 / 100", then five labeled bars (Documentation 85, Systems 63, Operations 70, Revenue 61, Financial & Diligence 82) on a graphite card with a steel border. Fills in Exit Yellow, track in steel, values in IBM Plex Mono. No shadow, no gradient.

Ref: `golden-atomic-brand-references/gabr-06-exit-readiness-scorecard.svg`

## Stat card (social/deck)

> A single statistic on a graphite card: a large IBM Plex Mono number in Exit Yellow (e.g. "7x"), a tracked-caps eyebrow above ("VALUATION UPLIFT"), one line of soft-white supporting copy, a faint Hollow 4 watermark top-right. Near-black, flat, no shadow.

Ref: `../templates/stat-card.svg`

## Always-stamp note

For any finished/distributed asset, reserve a clean band and stamp `../logos/raster/wordmark-white.png` or `../logos/raster/lockup-horizontal.png` — do not let the model render the wordmark text from scratch.
