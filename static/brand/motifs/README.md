# Motifs — Built for Exit

The recurring graphic signatures that make any asset instantly Built for Exit before the logo is even visible. Source SVGs (not screenshots) — edit and re-export freely. All pull the brand palette directly. Dark canonical, Exit Yellow at value moments only, no shadows.

| File | What it is | Use |
|------|-----------|-----|
| `dependency-diagram.svg` | Founder at center, every function wired to one person | Hero visual; "single point of failure" sections |
| `before-after.svg` | FOUNDER JOB → TRANSFERABLE ASSET, two-card transformation | Before/after sections; pitch decks |
| `scorecard.svg` | `72 / 100` Exit Readiness Score™ with five pillar bars | Assessment results; dashboards |
| `radar.svg` | Five-pillar exit-readiness radar (pentagon) | Exit Readiness Index™ feature; reports |
| `progression-rail.svg` | DEPENDENT → DOCUMENTED → SYSTEMIZED → TRANSFERABLE → EXIT READY | "The System" page; status rails |

**The two governing signatures:**

- **The Hollow 4** — the symbol (`../logos/`), used as watermark, favicon, footer element, merch. Never overused.
- **The single value moment** — in any composition, Exit Yellow marks exactly one thing (the score, the "after" column, the CTA). Steel + soft-white carry everything else. If yellow covers more than ~8% of a surface, pull back.

**Numbers** are always set in IBM Plex Mono. **Headlines** in the grotesk display face, uppercase. These motifs also seed the [Golden Atomic Brand References](../generation-layer/golden-atomic-brand-references/).
