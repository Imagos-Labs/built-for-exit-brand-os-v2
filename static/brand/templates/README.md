# Templates — Built for Exit

Reusable composition blocks as source files (not screenshots). Edit and re-export freely. Everything pulls from `/brand/tokens.css`, so a token change re-skins every template.

| File | What it is | Use |
|------|-----------|-----|
| `web-section.html` | Hero (a question), the five-lever framework grid, and a stat band — self-contained section blocks | Drop into any page; the canonical layout language |
| `invoice.html` | Dark invoice with the big 4 watermark, mono line-items, a yellow TOTAL row, "FREEDOM IS A SYSTEM" footer | Client invoices; a light inversion is one var swap |
| `stat-card.svg` | Single big metric atom (mono numeral, eyebrow, faint 4 watermark) | Social stat cards; deck slides |
| `podcast-lower-third.svg` | Broadcast name/title plate with the 4 badge and yellow accent rule | Podcast video lower-thirds |

Reference renders for these (and Ron's originals) live in `../brand-source/ron-rethink-2026-06-08/mockups/` (home, about, podcast, resources, the-system, invoices, lower-thirds).

## Rules every template inherits

- Dark is canonical. 1px steel borders. **No shadows, ever.**
- Headlines: grotesk display face, uppercase, tight. Numbers: IBM Plex Mono.
- Exit Yellow marks exactly one thing per block (the CTA, the total, the score).
- Always stamp the real wordmark on finished/distributed assets — never let an image model draw the wordmark text.
